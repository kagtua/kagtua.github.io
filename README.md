# kagtua.github.io

Personal site — React + Vite, deployed to [GitHub Pages](https://kagtua.github.io).

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```

## Deploy

Push to `main`. GitHub Actions builds and publishes automatically.

In the repo settings, set **Pages → Source** to **GitHub Actions** (one-time).
